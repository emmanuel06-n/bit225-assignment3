## Purpose
A single-page online library catalogue where users can browse, search, filter, add and borrow books.

## Technologies Used
HTML5, CSS3 (Grid, Flexbox, custom properties, media queries) and vanilla JavaScript. No frameworks or libraries.

## Main Features
- Book cards generated dynamically from a JavaScript array
- Live search by title
- Category filter that works together with the search
- "No books found." message when nothing matches
- Add Book form with validation and duplicate check (no page reload)
- Borrow button that reduces copies and shows "Out of stock" at 0
- Responsive layout: 3 columns (desktop), 2 (tablet), 1 (below 600px)
